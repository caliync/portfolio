Projects

Baylo

cd baylo/capstone

A barter trading platform. Capstone project with a 4-person team; I built the web platform, and my teammates built the mobile app.

4.89/5 from 100 respondents in the ISO/IEC 25010 evaluation I led

  • Built Baylo's web platform alone: a FastAPI backend with 9 route modules over a 13-table PostgreSQL database, and a React, TypeScript and Tailwind frontend where users post and trade items.
  • Added Gemini to estimate an item's value and category from its photos, screen listings for prohibited items, and score how well two items match for a trade (value, category, condition, interest).
  • Wired up Firebase for sign-in, real-time chat and notifications, and built an admin dashboard for users, listings, reports and trades.
  • Deployed the backend to Google Cloud Run in a Docker container.

FastAPI, PostgreSQL, React, TypeScript, Tailwind, Firebase, Gemini API, Docker, Cloud Run

Lakbay Lokal

cd lakbay-lokal

A free trip planner for the Philippines. Personal project, live.

  • Turns where you are staying and how far you will go into a timed day of local stops, with travel time between each.
  • Wrote the planning engine: it filters places by budget, group, opening hours and interests, scores them, and builds each day outward from the stay.
  • Limited every recommendation to a real place in its own dataset of about 220, so Gemini only rewords stored facts and never invents a venue.
  • Added editable plans, a rainy-day swap to indoor places, a day map, calendar and Markdown exports, and an offline day guide.
  • Added an owner sign-up form with review before anything goes live, tested the engine with unit tests, and deployed it on Render.

Python, FastAPI, JavaScript, SQLite, Gemini API, Leaflet, Render
